# Сравнение 10 UI-концептов лаунчера (обзорная волна v2)

Режим продукта — **Operate** (человек выполняет задачу: запустить игру, поставить мод).
Критерии оценки: сканируемость (нужное находится без чтения), плотность (данные в первом
экране), консистентность/предсказуемость (действия всегда в одних местах), стоимость
переноса в Tauri 2 + React + Tailwind. Контент во всех макетах идентичен; различие — только дизайн.

Дизайн-системы: `design-systems/<slug>/MASTER.md` (сгенерированы ui-ux-pro-max с дисками
variance/motion/density; финальные токены — в разделе «Арт-дирекция» каждого MASTER).
Контраст всех пар токенов проверен скриптом (текст ≥ 4.5:1, крупное/UI ≥ 3:1) — 10/10 PASS.
Горизонтального скролла нет ни при 1440×900, ни при 1280×720.

## Рекомендация top-3

### 1. «Сланец» (Графит) — база по умолчанию
Лучший баланс Operate-критериев. Список-строка — самая быстрая форма для выбора из 5–50
инстансов: имя, загрузчик, версия и время запуска читаются одной движущейся осью, глазу не
нужно прыгать по карточной сетке. Один холодный голубой акцент строго на действии (Играть /
Обновить) делает главный сценарий «сел и запустил» двухкликовым и предсказуемым. Моноширинные
версии исключают путаницу 0.17 / 26.3 / 47.3. Перенос в React + Tailwind дешёвый: это
фундаментальные компоненты (список, шапка, табы) без экзотики. С этого каркаса разумно
развивать продукт, заимствуя детали у других волны (телеметрия у «Пульта», полки у «ЦЕХа»).

### 2. «Пульт» (Пульт) — для инженерной аудитории и диагностики
Максимальная сканируемость данных: таблица со статусами, журнал событий и статусбар отвечают
на главный вопрос лаунчера «что сейчас происходит и почему не запускается» без открытия
логов. LED всегда дублирован текстом, моноширинный Fira Code выравнивает версии и счётчики
модов — 187 модов РЛКрафта читаются так же легко, как 14 у Fabric. motion 1 (только пульс
LED) и жёсткая 8px-сетка делают интерфейс самым «предсказуемым» в волне. Риск — холодность
для казуального игрока; хорош как второй режим «расширенный вид».

### 3. «Машинный зал» (ЦЕХ) — для продуктовой близости к Steam
Знакомая парадигма (библиотека слева, магазин/полки справа, статусбар снизу) означает нулевую
кривую обучения: любой, кто открывал Steam или Discord, уже «умеет» этим лаунчером. Плотность
10 позволяет держать на одном экране библиотеку, обновления и популярные модпаки — меньше
кликов в ежедневном цикле «запустил → обновил → играет». Янтарная кнопка ИГРАТЬ однозначно
доминирует. Риски: самый требовательный к типографической дисциплине вариант и умеренная
оригинальность (выглядит «как Steam» — это и сила, и ограничение бренда).

### Не recommending для v1 (но чем ценны)
- «Лента» — сильная идея для вкладки «Моды» (фид обновлений), но как главный экран смещает
  продукт в Experience-режим.
- «Кабина»/«Свечение» — яркие бренд-кандидаты для промо-поверхностей, в daily-инструменте
  их декор требует дисциплины.
- «Бумага», «Плед», «Девяносто Шесть», «Манифест» — нишевые характеры; их детали (редакционные
  заголовки, пилюли-цели, диалоги-«проводник», моно-нумерация) можно пересаживать по одному.
