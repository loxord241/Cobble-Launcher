Какие системные требования?

Windows 10 или 11, 64-битная система. Для первой загрузки игры нужен интернет. Подходящая Java устанавливается автоматически через Adoptium. Требования к памяти зависят от версии Minecraft и модов.

Это безопасно?

Лаунчер использует официальные источники и проверяет хэши скачанных файлов. Обновления лаунчера подписаны. Код открыт для проверки. Выбирайте моды внимательно: лаунчер не может гарантировать безопасность стороннего кода.

Где хранятся данные?

По умолчанию инстансы, кэш и настройки находятся в %LOCALAPPDATA%\mc-launcher-v2. Это каталог данных, а не путь установщика.

Как обновлять лаунчер?

Лаунчер сам проверяет новые версии и сообщает об обновлении. Нажмите кнопку установки: подпись проверяется, затем лаунчер перезапускается. Инстансы и профили сохраняются. Проверить вручную можно в настройках.

Почему вход Microsoft может не работать?

Вход через Microsoft одобрен Mojang и работает. Если он не удаётся — проверьте время системы и настройки прокси. Также доступны Ely.by и офлайн-профили; они не заменяют лицензию Minecraft.

Сколько это стоит?

Cobble Launcher бесплатен и распространяется под лицензией MIT. Лицензия Minecraft приобретается отдельно. Платных функций в лаунчере нет.

А CurseForge?

Каталог и обновления — Modrinth: открытый API и хэши файлов. Модпаки CurseForge (.zip с manifest.json) и .mrpack импортируются кнопкой «Импорт» или перетаскиванием файла в окно — загрузчик и моды подтянутся автоматически.

Будут версии для Linux или macOS?

Сейчас лаунчер работает только на Windows. Linux и macOS в планах, но без обещаний по срокам — лучше честно, чем «скоро».

Офлайн-профиль — это пиратство?

Файлы игры загружаются только с официальных серверов Mojang. Для серверов с проверкой Microsoft нужна купленная копия игры; офлайн-профили честно помечены как нелицензионные и не притворяются лицензионными.
