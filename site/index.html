Before your first launch

A few things worth knowing.

What are the system requirements?

Windows 10 or 11, 64-bit. You need internet access for the initial game download. A suitable Java version is installed automatically through Adoptium. Memory requirements depend on your Minecraft version and mods.

Is it safe?

The launcher uses official sources and checks downloaded file hashes. Launcher updates are signed. The code is open for inspection. Choose mods carefully: the launcher cannot guarantee the safety of third-party code.

Where is my data stored?

By default, instances, cache and settings are stored in %LOCALAPPDATA%\mc-launcher-v2. This is the data directory, not the installer location.

How do I update the launcher?

The launcher checks for new versions automatically and tells you when an update is available. Click install: it verifies the signature, then restarts. Your instances and profiles stay in place. You can also check manually in settings.

Why might Microsoft sign-in fail?

Microsoft sign-in is approved by Mojang and works. If it fails, check your system clock and proxy settings. Ely.by and offline profiles are also available; they do not replace a Minecraft licence.

How much does it cost?

Cobble Launcher is free and distributed under the MIT licence. A Minecraft licence is purchased separately. The launcher has no paid features.

What about CurseForge?

The catalogue and updates use Modrinth: an open API and file hashes. CurseForge modpacks (.zip with manifest.json) and .mrpack files are imported with the “Import” button or by dropping the file onto the window — the loader and mods are pulled in automatically.

Will there be Linux or macOS versions?

The launcher currently runs on Windows only. Linux and macOS are planned, but with no promise of dates — honest rather than “soon”.

Is an offline profile piracy?

Game files are downloaded only from official Mojang servers. Servers with Microsoft authentication require a purchased copy of the game; offline profiles are honestly marked as unlicensed and never pretend otherwise.
