# AUDIT: Реестр проблем и пробелов mc-launcher-v2

Документ ведётся в соответствии с требованиями аудита лаунчера:
1. Матрица фиче-гэпа против эталонных лаунчеров (Prism Launcher, Modrinth App, ATLauncher, Official Launcher).
2. Покрытие команд ядра в UI (IPC invoke vs generate_handler).
3. Реестр найденных и устранённых проблем (P0–P3).
4. Задокументированные сценарии верификации.

---

## 3. Реестр проблем и устранений

| № | Категория | Симптом (что видит юзер) | Repro | Корень | Фикс (коммит) | Проверка | Приоритет |
|---|---|---|---|---|---|---|---|
| 1 | Контракт ядра/UI | `Instance` сериализуется в `snake_case`, фронтенд мутирует ключи через костыли в `client.ts` | Вызов `instance_list` без `camelize` возвращает `mc_version`, `ram_mb` | На структуре `Instance` отсутствовал `#[serde(rename_all = "camelCase")]` | В процессе | `cargo test`, `m4_acceptance.cjs` | **P0** |
| 2 | Гонки и запуск | Двойной клик по «Играть» начинает 2 параллельных процесса `prepare` на одну папку, повреждая файлы | Два быстрых клика по Play или параллельный `instance_launch` | Отсутствует проверка `running_pid` и блокировка во время `prepare` | В процессе | Юнит-тест гонки запуска | **P0** |
| 3 | Жизненный цикл | Клик «Стоп» во время подготовки/скачивания выдает ошибку, а игра все равно запускается | Нажать «Играть» и сразу «Стоп» до спавна окна игры | `instance_kill` проверяет только PID из `.lock`, не отменяя задачи `engine` | В процессе | `kill_acceptance.cjs` + E2E тест отмены подготовки | **P0** |
| 4 | Гонки и запуск | Быстрый перезапуск сразу после Стопа стирает `.lock` нового процесса игры | Запустить, нажать Стоп и сразу Играть | `InstanceLock::drop` удаляет файл `.lock` безусловно, стирая чужой PID | В процессе | Юнит-тест `instance_lock_no_cross_delete` | **P0** |
| 5 | Целостность данных | Удаление или дублирование работающего инстанса приводит к ошибке Win32 AccessDenied и битым файлам | Вызвать `instance_delete` или `instance_duplicate` на запущенном инстансе | В `delete` и `duplicate` нет проверки `running_pid` | В процессе | Юнит-тест защиты от удаления запущенного | **P0** |
| 6 | Сеть и офлайн | Невозможно запустить установленный инстанс в офлайне, если манифест старше 1 часа | Отключить сеть, истечь TTL манифеста, вызвать `prepare` | `fetch_manifest` при ошибке сети выбрасывает ошибку вместо возврата stale-кэша | В процессе | Юнит-тест офлайн-старта со старым кэшем | **P0** |
| 7 | Диагностика | Игра упала с ошибкой при запуске — лаунчер молча сбрасывает статус, нет сообщения об ошибке | Запуск с несовместимой Java или OOM — окно закрывается | `launch_state` `exited` с ненулевым кодом не вызывает `crash_analyze` и не показывает UI | В процессе | E2E тест показа диалога краша с диагнозом | **P0** |
| 8 | Аккаунты | В UI нет возможности войти через Microsoft (MSA) и Ely.by, есть только дефолтный офлайн | Открыть чип профиля в титлбаре — нет кнопок входа | Отсутствие команд браузерного входа и модального окна управления профилями | В процессе | E2E тест добавления профилей | **P0** |
| 9 | Онбординг | Никнейм, введенный на шаге 2 онбординга, игнорируется и нигде не сохраняется | Пройти онбординг с ником `CustomNick` | В `Onboarding.tsx` значение `nick` не передавалось в ядро (`void nick`) | В процессе | `m4_acceptance.cjs` + проверка `accounts.json` | **P1** |
| 10 | Настройки инстанса | Нельзя изменить выделение памяти (RAM), JVM-аргументы и путь к Java для инстанса | Открыть карточку инстанса — нет настроек параметров запуска | Нет UI-интерфейса над `instance_settings_get/set` | В процессе | E2E тест изменения RAM и аргументов | **P1** |
| 11 | Управление инстансом | Нельзя переименовать инстанс из UI | Меню кебаба не содержит пункта «Переименовать» | `instance_rename` не был вызван в UI | В процессе | E2E тест переименования | **P1** |
| 12 | Логирование | Невозможно просмотреть логи инстанса и лаунчера из интерфейса | Сбой игры или поиск ошибок модов | Нет диалога LogViewer в UI | В процессе | E2E тест просмотра хвоста логов | **P1** |
| 13 | Сеть / Прокси | Изменение `proxyUrl` в настройках не применяется до перезапуска лаунчера | Изменить proxy в настройках | `AppState.http` создавался один раз при старте | В процессе | Юнит-тест обновления HttpClient при смене proxy | **P1** |
| 14 | Состояние UI | Вызов `useInstances.load()` сбрасывает статус `preparing`/`downloading` в UI | Обновление списка во время скачивания стирает прогресс-бар | `instances.ts` `load` затирал объект `status` | В процессе | Проверка сохранения статуса при `load()` | **P1** |
| 15 | Утечки ресурсов | Многократный вызов `subscribeEvents` создает дублирующиеся листенеры | Повторный рендер `Shell` | Отсутствовал флаг активной подписки | В процессе | Тест отписки/дедупликации листенеров | **P1** |
| 16 | Windows-специфика | Имя инстанса с точкой на конце (`Test.`) или именем `CON` ломает файловые пути | `sanitize_user_name("CON", "x")` давал `"CON"` | `sanitize_user_name` не срезал концевые точки и DOS-имена | В процессе | Юнит-тест `sanitize_user_name` | **P2** |
| 17 | Управление инстансом | Удаление инстанса не дает выбрать между корзиной и удалением навсегда | Удалить инстанс — стандартный prompt без выбора wipe | В UI захардкожено `wipe: false` | В процессе | Диалог подтверждения удаления с опцией wipe | **P2** |
| 18 | Управление Java | Нет возможности просмотреть список найденных версий Java и установить JRE из UI | Открыть настройки — нет секции управления Java | `java_list` и `java_install` не вызывались в UI | В процессе | Секция Java в Настройках и инстансе | **P1** |

## 4. Бэклог P2+ (некритичные улучшения)

1. **[P2] Вкладка установленных модов инстанса:** В ядре есть `content_installed`, позволяющий выводить список файлов модов в `mods/` инстанса. Реализация отдельного экрана со списком файлов и переключателями вкл/выкл модов (переименование `.jar` <-> `.jar.disabled`). Оценка: ~120 строк UI.
2. **[P2] Экспорт инстанса в .mrpack / zip:** Экспорт конфигурации инстанса для отправки друзьям. Оценка: ~80 строк бэкенда + UI кнопка.
3. **[P2] Скины в интерфейсе:** Отображение 3D-модели или рендера скина активного профиля Minecraft. Оценка: внешняя библиотека рендера скинов (~150 строк).
4. **[P3] Поиск по Настройкам:** Фильтрация полей на странице Настроек.
5. **[P3] Масштаб интерфейса (Zoom):** Настройка масштаба UI (80% / 100% / 125%) через CSS zoom / transform.
6. **[P3] Подробная история сессий:** График и таблица дат/длительности игровых сессий.
